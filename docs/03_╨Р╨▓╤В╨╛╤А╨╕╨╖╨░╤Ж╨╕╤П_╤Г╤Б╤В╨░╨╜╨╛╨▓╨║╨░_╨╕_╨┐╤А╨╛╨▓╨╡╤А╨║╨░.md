# Практическая часть: регистрация и авторизация

## Что реализовано

- страницы регистрации и входа на HTML5/CSS3;
- серверная обработка на PHP;
- подключение к MySQL через PDO;
- `PDO::ATTR_EMULATE_PREPARES = false` и подготовленные запросы для защиты от SQL-инъекций;
- хеширование паролей `password_hash()`;
- проверка паролей `password_verify()`;
- серверная валидация имени, email и пароля;
- проверка уникальности email;
- CSRF-защита HTML-форм;
- регенерация session ID после входа;
- защищённый личный кабинет;
- выход из системы;
- JSON REST endpoints `/backend/public/api/*.php` для будущего React-клиента.

## Установка

1. Скопировать проект в `C:\xampp\htdocs\finance-assistant-control-point`.
2. Запустить Apache и MySQL в XAMPP.
3. Открыть `http://localhost/phpmyadmin/`.
4. Импортировать `database/install.sql`.
5. Открыть `http://localhost/finance-assistant-control-point/`.
6. Зарегистрировать нового пользователя.
7. Выйти и войти с созданными данными.

## Демонстрационный аккаунт

После импорта `database/install.sql` можно войти:

- email: `egor.demo@example.com`
- пароль: `Demo123!`

## Проверка защиты от SQL-инъекций

Форма принимает пользовательский ввод только как параметры подготовленных PDO-запросов. Строки вроде `' OR 1=1 --` не выполняются как часть SQL-команды и не позволяют войти без корректного пароля.

## Проверка валидации

Примеры, которые должны быть отклонены сервером:

- пустое имя;
- email без корректного формата;
- пароль короче 8 символов;
- пароль без цифры;
- несовпадающие пароли;
- повторная регистрация существующего email.

## API

`POST /backend/public/api/register.php` — регистрация.

`POST /backend/public/api/login.php` — авторизация.

`POST /backend/public/api/logout.php` — выход.

`GET /backend/public/api/csrf.php` — выдача CSRF-токена для текущей сессии.

`GET /backend/public/api/me.php` — текущий пользователь.

Перед API-запросами с изменением состояния должен использоваться CSRF-токен, полученный через серверную сессию.

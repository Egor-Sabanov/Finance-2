# Состав архива для показа

Каждый выдаваемый ZIP должен содержать рабочий проект и актуальную папку `Документы`:

- отчет по контрольным точкам;
- анализ предметной области;
- черновое техническое задание;
- полную инструкцию по показу проекта и базы данных;
- ER-диаграмму: редактируемый оригинал `.drawio` и файлы просмотра `.png` и `.svg`.

Сведения в отчете и инструкции обновляются при изменении приложения или процесса показа. ER-диаграмма сверяется с `database/schema.sql`. Полный архив называется `Finance-2-full-package.zip`.

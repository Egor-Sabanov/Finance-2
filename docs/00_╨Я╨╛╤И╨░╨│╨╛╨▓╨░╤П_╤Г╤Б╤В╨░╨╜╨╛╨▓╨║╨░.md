# Полная установка проекта на Windows + XAMPP

## 1. Распаковка

Распакуйте проект в:

`C:\xampp\htdocs\finance-assistant-control-point`

## 2. XAMPP

Запустите Apache и MySQL.

## 3. База данных

Откройте `http://localhost/phpmyadmin/` → **Импорт** → выберите `database/install.sql` → **Импорт**.

После этого будет создана БД `finance_app` с таблицами:

`users`, `categories`, `transactions`, `import_batches`, `budgets`, `budget_limits`, `notifications`.

В `install.sql` находятся также тестовые `INSERT`.

## 4. Проверка PHP → MySQL

Откройте:

`http://localhost/finance-assistant-control-point/backend/public/health.php`

Ожидаемый результат — JSON со статусом `ok` и базой `finance_app`.

## 5. Проверка регистрации

Откройте:

`http://localhost/finance-assistant-control-point/frontend/register.php`

Введите имя, корректный email и пароль не короче 8 символов с буквой и цифрой.

После отправки пользователь должен появиться в таблице `users`.

## 6. Проверка авторизации

Откройте:

`http://localhost/finance-assistant-control-point/frontend/login.php`

Введите созданные данные. После успешного входа откроется `dashboard.php`.

## 7. Проверка SQL-инъекции

В поле email не нужно пытаться обходить систему: тестовая строка `' OR 1=1 --` должна быть воспринята как обычный ввод и не должна давать доступ.

## 8. Проверка Git

В корне проекта:

```bash
git status
git log --oneline --decorate --graph --all
```

## 9. Проверка кода

```bash
php -l frontend/login.php
php -l frontend/register.php
php -l frontend/dashboard.php
php -l backend/src/bootstrap.php
php -l backend/public/api/register.php
php -l backend/public/api/login.php
php tests/auth_static_check.php
```

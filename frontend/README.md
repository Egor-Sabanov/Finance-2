# Веб-интерфейс

Интерфейс собран на PHP и HTML/CSS, соединение с MySQL и проверка сессий выполняются сервером.

- `login.php`, `register.php`, `logout.php` — вход, регистрация и выход;
- `dashboard.php` — личный кабинет;
- `transactions.php` — список операций текущего пользователя, поиск по описанию и категории, фильтры по типу, категории и датам;
- `transaction.php?id=…` — подробности операции. Пользователь видит только свои записи, администратор может открыть любую;
- `admin-transactions.php` — поиск, фильтры и список всех операций. Страница доступна только роли `admin`.

Новые регистрации получают роль `user`. Для новой установки импортируйте `database/install.sql`, затем при необходимости `database/test_data.sql` (демо-администратор: `egor.demo@example.com`, пароль `Demo123!`). Для существующей базы выполните `database/migrate_roles.sql` ровно один раз. Назначить роль администратора можно запросом `UPDATE users SET role = 'admin' WHERE email = 'адрес';`.

Страницы операций используют параметризованные запросы и проверяют владельца записи на сервере. Ограничения поиска и фильтров применяются к SQL-запросу, а не только к отображённым строкам.

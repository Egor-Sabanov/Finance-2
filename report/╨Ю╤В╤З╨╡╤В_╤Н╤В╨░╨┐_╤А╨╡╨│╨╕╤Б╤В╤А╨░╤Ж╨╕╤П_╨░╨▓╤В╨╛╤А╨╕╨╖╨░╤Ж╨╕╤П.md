# Отчёт по этапу «Регистрация и авторизация»

## Цель

Реализовать рабочую регистрацию и авторизацию пользователя с серверной валидацией, хешированием паролей, подключением к MySQL и защитой от SQL-инъекций.

## Реализовано

1. Страница регистрации.
2. Страница входа.
3. Серверная проверка входных данных.
4. Проверка уникальности email.
5. Хеширование паролей.
6. Проверка пароля при входе.
7. PDO prepared statements.
8. CSRF-защита форм.
9. Session ID regeneration после авторизации.
10. Личный кабинет авторизованного пользователя.
11. Выход из системы.
12. API endpoints для дальнейшего React-клиента.

## Демонстрационный сценарий

1. Открыть страницу регистрации.
2. Создать новый аккаунт.
3. Проверить появление пользователя в `users`.
4. Выполнить вход.
5. Убедиться, что открылся личный кабинет.
6. Проверить ошибочный пароль.
7. Проверить повторную регистрацию того же email.
8. Проверить выход.

## Итог

Требования текущего этапа выполнены: созданы страницы регистрации и авторизации, добавлена серверная валидация, хеширование паролей, работа с БД через PDO и защита от SQL-инъекций.
